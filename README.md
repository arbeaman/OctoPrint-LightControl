# OctoPrint Light Control
This OctoPrint plugin provides remote control of 3D printer lights.

Lights can be switched on or off manually from the OctoPrint nav bar, and automatically
turned **on** when user-specified commands are sent to the printer and/or turned **off**
when the printer is idle.

Switching and sensing can be handled through a compatible sub-plugin (such as
[OctoPrint-LightControl-TPLink](https://github.com/arbeaman/OctoPrint-LightControl-TPLink)),
G-code or system commands, or GPIO pins.

Click the lightbulb icon in the nav bar to toggle the light on or off:
